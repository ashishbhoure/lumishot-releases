# Lumishot for Windows

Screenshots and screen recordings that look good enough to post: capture with a hotkey, put the
shot on a background, mark it up, trim recordings or turn them into GIFs, then copy, save or drag
them anywhere.

## Download

Get **Lumishot-Setup-x.y.z.exe** from the [latest release](../../releases/latest) and run it.
Windows 10 (version 2004 or later) or Windows 11, 64-bit.

The installer is not code-signed yet, so Windows SmartScreen may say it "protected your PC".
Click **More info → Run anyway**.

Lumishot starts with Windows and waits in the system tray. Installed copies update themselves from
this page.

| Shortcut      | Does                  |
| ------------- | --------------------- |
| `Alt+Shift+S` | Capture a region      |
| `Alt+Shift+F` | Capture full screen   |
| `Alt+Shift+R` | Start or stop recording |

Shortcuts can be changed in Settings.
